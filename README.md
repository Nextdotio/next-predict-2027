# NEXTPredict 2027 — Partnership Rate Card

Sponsorship brochure for NEXTPredict 2027, the prediction markets summit
(October 2027, New York City — exact dates and venue TBA).

Single-page React app (Vite + Tailwind). Product data, ticket ladder,
recognition tiers and the investment calculator live in `src/App.jsx`.

```
npm install
npm run dev      # local dev server
npm run build    # production build
npm run deploy   # build + publish dist/ to gh-pages
```

Pricing source: `NEXTPredict_2027_Commercial_Master.xlsx` (2027 rate card,
reconciled 27 Aug 2026). See `CLAUDE.md` for editing conventions.
